Setup
  1. Use Chrome or Edge on a laptop (not a phone).
  2. Once per laptop: install the CP210x USB driver from Silicon Labs.
  3. Plug in the Turtle USB cable. Unplug Bluetooth on the robot.
  4. On the public site use Download .ino and upload with Arduino IDE. Upload to Turtle appears only when you run this project locally (npm run setup:cli then npm run dev → http://localhost:5173/code.html).
  1. Python 3: py -3 --version. For the camera, install a decoder before joining Tello Wi-Fi: winget install --id Gyan.FFmpeg -e (restart the terminal after install).
  2. Sample controller (keys + camera): Download tello_pc.py → join TELLO-xxxxxx → py -3 tello_pc.py.
  3. Snap blocks here, then Download Tello program → py -3 tello_mission.py while on Tello Wi-Fi.
