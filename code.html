Setup
  1. Install Arduino IDE from academy.arduino.cc/pages/download-software (desktop app, not the Microsoft Store).
  2. Install the CP210x UART driver for Windows and Mac from Silicon Labs USB to UART downloads.
  3. Open turtle.ino in Arduino IDE.
  4. Tools → Board → Arduino Uno.
  5. Tools → Port → CP210x COM or cu.SLAB_USBtoUART. Not COM1.
  6. Unplug the Bluetooth module, then Upload.
  1. Python 3: py -3 --version. Camera decoder: see Setup (FFmpeg or OpenCV) before joining Tello Wi-Fi.
  2. Test flight (keys + camera) is on the Setup tab — not this Coding download.
